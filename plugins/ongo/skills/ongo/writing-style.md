# Writing style

Concise, precise, information-dense. Favour code and mathematics over prose. When prose is necessary: state the point, support it once, stop.

No throat-clearing, no signposting, no recycled rhetorical tics (e.g. "load-bearing", "the heart of", "non-trivial"). One adjective per noun maximum. Strong nouns and verbs do the work.

Tables and lists when they fit the data. Code blocks for code, math blocks for math, full sentences only when neither fits.
